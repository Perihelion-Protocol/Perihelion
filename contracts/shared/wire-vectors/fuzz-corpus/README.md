# Differential Fuzzing Corpus

This directory holds payloads generated by the Rust proptest fuzzer for cross-language validation with the Solidity decoder.

## Purpose

The Rust fuzzer exports adversarial and edge-case payloads here as `.hex` files. The EVM test suite (`CrossValidate.t.sol`) reads these files and validates that the Solidity decoder handles them identically to the Rust decoder — either accepting with identical field values, or rejecting with the same error.

## File Naming Convention

- `<message_type>_<mutation>.hex` — adversarial payloads
- `<message_type>_<case_id>.hex` — edge cases from proptest

Examples:
- `fill_confirmed_nonzero_high.hex` — FillConfirmed with non-zero high bytes in `solver_evm`
- `cancel_intent_bad_reason.hex` — CancelIntent with unknown reason code

## Generated Files

These files are **generated** by running:
```bash
cd contracts/soroban/settlement
PROPTEST_CASES=100 cargo test fuzz -- --test-threads=1
```

Do not edit manually. To regenerate:
```bash
rm -rf contracts/shared/wire-vectors/fuzz-corpus/*.hex
./scripts/run-differential-fuzz.sh bounded
```

## Git Tracking

This directory is tracked in git to preserve interesting edge cases discovered during fuzzing. When a new class of divergence is found:

1. Proptest generates a regression file in `proptest-regressions/`
2. The corpus export writes the failing payload to this directory
3. Commit both files to ensure the regression is tested in CI

## CI Integration

The `differential-fuzz.yml` workflow:
1. Runs the Rust fuzzer to generate corpus files
2. Uploads them as artifacts
3. Downloads them in the `cross-validate` job
4. Runs `CrossValidate.t.sol` to verify Solidity handles them correctly

## Local Validation

After generating the corpus locally:
```bash
cd contracts/evm
forge test --match-contract CrossValidate -vv
```

To inspect a specific payload:
```bash
cat fill_confirmed_nonzero_high.hex
# 0x0102111111111111111111111111111111111111111111111111111111111111111111111111ff00000000000000000000aaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaaa00000000000000000000000000000f424000000000000000002a
```

Decode manually:
```bash
cast abi-decode "decodeFillConfirmed(bytes)" $(cat fill_confirmed_nonzero_high.hex)
```

## Cleanup

To remove stale corpus files (e.g., after refactoring message types):
```bash
rm contracts/shared/wire-vectors/fuzz-corpus/*.hex
git add -u contracts/shared/wire-vectors/fuzz-corpus/
git commit -m "Clean differential fuzz corpus"
```
